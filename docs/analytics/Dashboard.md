# Executive Dashboard Documentation

The **Executive Dashboard** consolidates all key indexes in a single-screen responsive workspace.

## Key Sections

1.  **Vue Générale (Scorecards)**: Quick check of active birds, fertility rates, cash flow, consanguinity, and completeness scores (DQI).
2.  **Critical Warnings (DSS)**: Highlight anomalies like high consanguinity ($F > 6.25\%$), overcrowded cages, or low registry scores.
3.  **Projections (30D Forecasts)**: Forecast future egg counts and sevrages using deterministic cohorts.
4.  **Biological Timelines**: Visualize nesting and veterinary events.
