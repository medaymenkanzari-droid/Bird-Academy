# Export Center

The **Export Center** translates and packages databases into four file formats:

## Formats

1.  **CSV (Comma-Separated Values)**: Lightweight raw tabular files.
2.  **Excel (XLS)**: Formatted tab-separated files ready for spreadsheet processors.
3.  **JSON (Structured Object)**: Direct database state dumps, ideal for backups.
4.  **ZIP (Simulated Batch Text)**: Consolidates multiple tables in a single text bundle.

All exports respect active filters, custom column choices, and target translations.
