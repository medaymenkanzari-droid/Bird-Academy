# Graph Engine

The **Graph Engine** leverages Recharts to provide ten responsive visual components.

## Rendered Graphs

1.  **Line Chart**: Tracks population variations (N vs N-1).
2.  **Bar Chart**: Compares breeding outputs per season.
3.  **Area Chart**: Displays financial cash-flow transitions.
4.  **Pie Chart**: Visualizes category proportions (breed, expenses).
5.  **Radar Chart**: Captures multidimensional performance ratings.
6.  **Scatter Plot**: Relates age to inbreeding coefficients.
7.  **Stacked Bar**: Separates fertile vs clear egg ratios.
8.  **Histogram**: Displays cohort distributions.
9.  **Heat Map**: Illustrates weekly event densities.
10. **Timeline**: Charts nesting biological milestones.
