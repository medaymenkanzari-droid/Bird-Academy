## 1. Objectif du Programme de Test Public

Le programme de test public vous confie la version **V2.0.0-RC1** pour valider son comportement sur le terrain :
- Gestion courante d'élevage (oiseaux, bagues, couples, pontes, soins).
- Fonctionnement **100% hors-ligne (Offline)** sans dépendance cloud.
- Respect absolu de la vie privée des données de l'élevage.

---

## 2. Étapes d'Accueil

1. **Téléchargement sécurisé :**
   Téléchargez l'application depuis le centre officiel et vérifiez les empreintes SHA-256 :
   - Setup Windows : `Bird-Academy-Avian-ERP-Setup.exe` (109 747 064 octets)
   - Portable Windows : `Bird-Academy-User.exe` (109 408 543 octets)
   - APK Android : `Bird-Academy-User.apk` (20 461 460 octets)
2. **Premier démarrage :**
   L'application s'ouvre directement sans création de compte internet.
3. **Plan GRATUIT (FREE) :**
   Accès immédiat jusqu'à 20 oiseaux vivants.
4. **Licence de test (30 jours) :**
   Activation par clé `LMSE-TEST-XXXX-XXXX-XXXX` pour débloquer l'ensemble des modules d'évaluation.
