# Aide-Mémoire & Checklist Première Session de Test — Bird Academy Enterprise
**Version Cible :** `v1.3.6`  
**BUILD_ID :** `BA-V1.3.6`  
**Destinataires :** Éleveurs et testeurs de la campagne publique  

---

## AVANT DE COMMENCER (CONSIGNES DE SÉCURITÉ ET DONNÉES)

Avant de lancer votre toute première session de test, veuillez lire attentivement ces recommandations essentielles :

1. **Sauvegardez vos données importantes :** Si vous utilisez déjà une version de travail ou si vous avez des données de valeur, effectuez un export de sauvegarde préalable depuis **Paramètres > Sauvegarder**.
2. **Utilisez uniquement des données autorisées :** N'utilisez que des données dont vous êtes le propriétaire ou que vous êtes libre d'utiliser pour un test.
3. **Protégez vos informations personnelles :** Ne partagez jamais d'informations privées inutiles (mot de passe, identifiants bancaires, adresse personnelle exacte). Un simple pseudonyme ou prénom suffit pour votre fiche testeur.
4. **Confidentialité de l'élevage :** N'envoyez pas de données d'élevage confidentielles ou sensibles sans nécessité absolue pour la résolution d'une anomalie.
5. **Ne supprimez rien artificiellement :** Ne supprimez jamais vos oiseaux ou données réelles existantes uniquement pour "faciliter" le passage d'un test.
6. **Ne modifiez pas les fichiers système :** Ne tentez pas d'éditer ou de supprimer manuellement les fichiers de l'application dans Windows ou Android, sauf si le protocole de test vous le demande explicitement.

---

## LES 13 ÉTAPES D'UNE SESSION DE TEST RÉUSSIE

Cochez chaque étape au fur et à mesure de votre progression :

- [ ] **Étape 1 : Installer l'application officielle**  
  Téléchargez et installez `Bird-Academy-User-Windows-Setup.exe` (ou version portable sur PC, ou `Bird-Academy-User.apk` sur Android).
  
- [ ] **Étape 2 : Vérifier la version v1.3.6**  
  Au lancement, assurez-vous que le numéro de version affiché est bien **`v1.3.6`**.

- [ ] **Étape 3 : Vérifier le BUILD_ID BA-V1.3.6**  
  Dans le menu **Paramètres**, vérifiez que l'identifiant de fabrication est bien **`BA-V1.3.6`**.

- [ ] **Étape 4 : Lire les informations de test**  
  Consultez rapidement le Guide d'Accueil ([QA_PUBLIC_TESTER_ONBOARDING_v1.3.6.md](file:///d:/app%20canaris/28+/QA_PUBLIC_TESTER_ONBOARDING_v1.3.6.md)).

- [ ] **Étape 5 : Accepter les conditions de participation**  
  Donnez votre accord libre pour consigner fidèlement vos observations (consentement éclairé).

- [ ] **Étape 6 : Enregistrer l'environnement réel**  
  Notez simplement votre matériel : ordinateur (ex: PC portable Windows 11) ou smartphone (ex: Samsung Android 14).

- [ ] **Étape 7 : Commencer la session**  
  Notez l'heure de démarrage de votre test.

- [ ] **Étape 8 : Exécuter uniquement les scénarios assignés**  
  Réalisez les actions prévues (ex: saisie des 20 premiers oiseaux, tentative d'ajout d'un 21e oiseau, test du mode hors-ligne, changement de langue en arabe RTL).

- [ ] **Étape 9 : Noter les observations réelles**  
  Décrivez simplement ce que vous voyez à l'écran : clarté des menus, rapidité, compréhension des messages de quota.

- [ ] **Étape 10 : Capturer uniquement les preuves nécessaires**  
  Si un résultat remarquable est validé, prenez une capture d'écran simple (`Impr Écran` sur PC ou touches `Volume Bas + Marche` sur mobile).

- [ ] **Étape 11 : Signaler immédiatement tout incident**  
  Si un bouton ne répond pas ou si une erreur survient, remplissez la fiche d'incident ([QA_PUBLIC_INCIDENT_REPORT_FORM_v1.3.6.md](file:///d:/app%20canaris/28+/QA_PUBLIC_INCIDENT_REPORT_FORM_v1.3.6.md)).

- [ ] **Étape 12 : Terminer la session**  
  Notez l'heure de fin de votre session de manipulation.

- [ ] **Étape 13 : Enregistrer le résultat réel**  
  Transmettez votre retour via le formulaire rapide ([QA_PUBLIC_FEEDBACK_QUICK_FORM_v1.3.6.md](file:///d:/app%20canaris/28+/QA_PUBLIC_FEEDBACK_QUICK_FORM_v1.3.6.md)).

## RAPPEL D'INTÉGRITÉ
> Ne tentez jamais d'inventer une session ou de deviner un résultat. Une observation sincère indiquant *"je n'ai pas compris ce bouton"* a dix fois plus de valeur pour l'équipe qu'un faux succès !
