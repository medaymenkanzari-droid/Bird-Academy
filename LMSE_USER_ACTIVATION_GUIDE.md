# Guide Utilisateur — Activation de Licence Bird Academy (LMSE)

Bienvenue dans **Bird Academy Enterprise / Volière Manager**.

Ce guide explique étape par étape comment activer votre licence lors du tout premier démarrage sur un nouvel appareil (PC Windows, Mobile Android ou PWA).

---

## Étape 1 : Premier Lancement de Bird Academy
1. Lancez l'application **Bird Academy** sur votre appareil.
2. Lors de la toute première exécution, l'écran de bienvenue et d'activation s'affiche automatiquement :
   - **Titre** : *Bienvenue dans Bird Academy*
   - **Sous-titre** : *Activez votre licence pour commencer.*

---

## Étape 2 : Saisie de votre Clé de Licence
1. Saisissez votre clé de licence au format officiel : `LMSE-XXXX-XXXX-XXXX` (ex: `LMSE-COMM-A1B2-C3D4-E5F6`).
2. *(Optionnel)* Entrez le nom de votre élevage ou votre nom de titulaire.
3. Cliquez sur **Activer Bird Academy**.

---

## Étape 3 : Validation & Confirmation
- Si votre clé est valide et que votre appareil n'a pas dépassé la limite d'appareils autorisée, l'écran de confirmation s'affiche :
  - **Statut** : `✓ Licence activée`
  - **Type de licence** : BETA, Commerciale, Enterprise, etc.
  - **Date d'expiration**
  - **Appareils enregistrés** : ex. `1 / 3`
- Cliquez sur **Continuer** pour accéder immédiatement à l'application Bird Academy.

---

## Que faire si votre clé est refusée ?

### 1. "Clé de licence non reconnue" / Format invalide
- Vérifiez qu'il n'y a pas d'erreur de frappe dans la clé.
- Le format doit comporter le préfixe `LMSE-`.

### 2. "Nombre maximal d'appareils atteint"
- Votre licence autorise un nombre limité d'appareils. Contactez l'administrateur de votre licence pour désassocier un ancien appareil ou augmenter votre quota.

### 3. "La licence a expiré"
- Votre licence temporaire ou d'essai est arrivée à terme. Vous devez renouveler votre licence auprès de votre administrateur.

### 4. "Licence révoquée"
- La licence a été annulée par l'administrateur Enterprise.

---

## Activer en Mode Hors Ligne (Sans Internet)

Si votre appareil n'a pas d'accès Internet au moment de l'activation :
1. Sur l'écran d'activation, cliquez sur le lien **Activation Hors Ligne (Offline)**.
2. Entrez votre clé de licence.
3. Cliquez sur **1. Générer le Code Défi Matériel**.
4. Copiez le **Code Défi Matériel** généré (ex: `CHALLENGE-XXXX-XXXX`) et transmettez-le à votre administrateur.
5. L'administrateur vous fournira un **Code de Réponse Hors Ligne**.
6. Saisissez ce code dans le champ prévu et cliquez sur **2. Valider l'Activation Hors Ligne**.

---

## Vérifier l'état de votre licence après activation
Une fois activée, votre licence reste enregistrée sur votre appareil. Vous pouvez consulter les détails de votre licence à tout moment depuis les **Paramètres** de Bird Academy.
